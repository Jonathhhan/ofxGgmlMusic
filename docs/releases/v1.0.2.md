# ofxGgmlMusic v1.0.2

## Compatibility

- openFrameworks: `of_v20260406_vs_64_release`
- minimum `ofxGgmlCore`: `1.0.1` / commit `e3ea42a`
- `OFXGGML_MUSIC_VERSION_STRING`: `1.0.2`

## Highlights

- Added `ofxGgmlMusicExternalGenerationBackend` as the explicit bridge boundary
  for local model-backed music generator executables.
- Added external generation contract coverage for WAV, manifest, history, MIDI,
  and stem outputs.
- Added a user-facing external generation CLI and opt-in Hugging Face
  Transformers MusicGen optional Python runner profile.
- Allowed external model identifiers when `requireModelPathExists` is disabled.
- Added draggable waveform scrubbing to the generation and AceStep examples.
- Kept the procedural backend warning-clean on MSVC by making sample narrowing
  explicit.

## Runtime Scope

This release includes the built-in procedural prompt-to-music backend, the local
external generator bridge, a no-IDE external generation CLI, and an optional
Python runner profile for Hugging Face MusicGen workflows.

Generated audio, MIDI, manifests, histories, model binaries, and build outputs
remain local artifacts outside git.
